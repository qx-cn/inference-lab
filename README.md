# inference-lab

记录推理引擎、性能优化相关的实验、学习笔记和复现材料。

## 目录

- [学习笔记](notes/README.md)：原理梳理、源码阅读和资料索引。
- [实验记录](experiments/README.md)：实验目标、复现步骤和结果。
- [实验模板](templates/experiment.md)：复制后填写，保留可复现信息。

## 记录方式

学习笔记按主题命名，例如 notes/kv-cache.md。实验按日期和主题建立目录，例如 experiments/2026-11-01-batching/，在目录内保存 README.md、脚本、配置和小型结果文件。

实验记录包含硬件与软件版本、模型与数据版本、完整命令、基线、测量口径和原始结果。结论写明适用条件，未测量的内容标为待验证。

仓库不提交凭据、企业源码、内部日志或内部地址。模型权重、大型数据和性能追踪文件保存在仓库外，记录合法可访问的来源、版本与校验值。
